# Product Vision

Birthday Experience Studio enables people with little or no technical experience to create deeply personal interactive birthday gifts.

The creator should not need to know what to write. BES should progressively help uncover useful material through understandable questions, examples, “I don't know” paths, guided writing and optional external-AI prompt preparation.

## Two product surfaces

### Studio

Private authoring environment containing relationship context, memories, drafts and guidance.

### Experience

Recipient-facing gift assembled from explicitly selected content and Experience Blocks. It must not leak private Studio context.

## Long-term direction

The architecture should support many relationship types, dynamic question packs, reusable blocks, themes, media, localization, multiple projects, migrations, additional exporters and optional future AI integrations.

Birthday is the first domain. Do not prematurely generalize the UI into a generic celebration product, but avoid architectural decisions that make future occasion types impossible.

## Success

A novice can create something that feels genuinely made for one particular person rather than filling out a generic greeting-card template.

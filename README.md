# Birthday Experience Studio

> Early development — evolving 0.x architecture, not a finished product.

Birthday Experience Studio (BES) is a local-first creator for highly personal, interactive birthday experiences that can be exported as portable offline HTML gifts.

## Product principles
- Beginner-first: no programming or prompt-engineering knowledge required.
- Adaptive: questions and experiences adapt to the person, relationship and situation.
- Local-first and privacy-first.
- AI is optional and external: BES prepares high-quality prompts; it does not require an AI API.
- Modular: relationship types, question packs, experience blocks, themes and exporters are extensible.
- Creator data and recipient-facing exports are strictly separated.
- The single HTML file is an export format, not the development architecture.
- This repository is designed for continuous development by multiple coding agents.

## Initial vertical slice
Start → recipient/relationship → adaptive questions → writing → preview → single-file offline HTML export.

See `AGENTS.md` and `docs/` before making architectural changes.

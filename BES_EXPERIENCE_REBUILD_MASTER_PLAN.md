## Concrete before/after checks

Before: eight fixed roles; the same three choices only change a sentence; theme cycling is called Surprise Me; all finales share the same 13.5-second script; photos stack as cards. After: legacy Champion preserved, three maintained Challenger strategies select different arcs and optional content beats; a deliberate recipient choice prioritizes a real available beat; alternate composition changes ordering/surprise pattern while preserving content; photo exhibit and finale presentation fit each strategy. Missing photos never pretend to be memories. Public authored text supplies emotional peaks; private answers are excluded.

Technical acceptance checks deterministic strategy differences, explicit legacy adoption, exact content coverage, schema bounds, CSP hash, hostile inputs/URLs, export allowlist, no-network playback, dynamic navigation/back/replay, reduced motion and mobile. Experience acceptance records curiosity, variety, consequential interaction, surprise, personal peak, earned finale and creator pleasure as observed judgments, with limitations. Passing tests is not a Wow claim.
